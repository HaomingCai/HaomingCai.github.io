# 迭代记录

## Baseline（原站）

纯黑底 + 纯白字，三种打架的强调色（蓝/黄/橙），缩略图比例参差不齐，字号层级几乎不存在（全是 14px），`default.html` 里 4 段重复 Liquid（1400 行）。

---

## 阶段 A：配色探索（v1 / v2 / v3）

三版**共用同一套排版骨架**，只换强调色 —— 这样对比才是公平的，你看到的差异纯粹来自配色。

### 骨架层面的共同改动（相对 baseline）

| 项 | 改动 |
|---|---|
| 代码结构 | `default.html` **1400 行 → 130 行**；4 段重复 Liquid 抽成 `_includes/publication.html` |
| 字体 | 三级分工：Cormorant Garamond（衬线大标题）/ Inter（正文）/ JetBrains Mono（元信息） |
| 底色 | 纯黑 `#000` → 暖米白（非纯白） |
| 缩略图 | 统一 `150px × 4:3 cover` —— 参差不齐的左边缘消失 |
| 强调色 | 3 种 → **1 种** |
| 间距 | 统一 8px 基准（8/16/24/40/64/96） |
| "Let's Chat!" 蓝框 | 删除，融进 bio 一行 |
| ClustrMaps | 删除 |
| 视频 JS | 200 行 setInterval 轮询 → 20 行 CSS 动画时序计算 |
| 作者链接 JS | 正则暴力替换 innerHTML → TreeWalker 只动文本节点（不再有破坏 DOM 的风险） |
| 猫咪画廊 | 保留，移到底部，默认灰度、hover 恢复彩色 |

### 评语

- **v1 墨蓝 (87)** — 安全、学术、耐看。但蓝色链接和任何一个普通网页的超链接毫无区别，**没有记忆点**。
- **v2 赤陶 (89)** ⭐ — 暖赤陶配奶油底，正是 anthropic / mengweiren 气质的来源。有个性、有温度，在一堆蓝色学术主页里能被记住。**我的推荐。**
- **v3 苔绿 (84)** — **失败**。饱和度太低，在页面上读不出"绿"，看着像一个偏色的灰。强调色的意义被浪费了。

### 已修的 bug（过程中发现）

- **截图脚本漏报**：`loading="lazy"` 导致 Playwright fullPage 截图时屏幕外的图（SR 缩略图 + 整个猫咪画廊）全是空白。**这是截图工具的 bug，不是网站的 bug** —— 懒加载对真实站点是好事，所以修的是截图脚本（先滚一遍页面再拍），并加了破图 / 横向溢出的自动检查。
