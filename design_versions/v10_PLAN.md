# Loop Plan — v10 series（v20 高效感 × 今天的个性/风格 的融合)

## 北极星
把 **v20 的高效信息传递 + 专业感**，和 **Usha 那套个性外壳**融合。
**内容是主人，个性在页边。专业感永远优先。** 在不影响信息传递和专业感的前提下，
天马行空地发挥（尤其围绕"猫 + 猫爪 + 光/成像"这些他喜欢的点）。

## 不可动的底线（每一轮自动检查）
- 交互 scrub 图（拖动看打光 / 拉焦）+ 缩略图分组论文表 = v20 的实质，必须原样能玩。
- WCAG AA 对比度通过；无横向溢出；无破图（snap 脚本自动查）。
- 线上首页 `/` 一个字不动；只在 `/usha.html` 预览页上迭代。
- 保留他明确喜欢的：插画猫、猫爪滚动动画、插画肖像、手绘名字。
- 任何"好玩"都不能牺牲可读性 / 专业感。

## 版本管理
每一轮存一个 `design_versions/v10_XX/`（desktop.png + mobile.png + 布局源码副本 + 一行 changelog）。
`v10_00` = 当前 mix 版基线。

## 待办 backlog（有序；我每轮用自我批判重排优先级）
- **v10_00** — 把当前 mix 版快照为基线。
- **v10_01** — **删掉右边那个相机/镜头插图（你说难看）。** 重新设计右侧留白：
  给你看 2–3 个更柔和的方向（只留飘动的暖色散景光斑 / 柔光晕染 / 干脆留白干净 / 一株小植物），你选。
- **v10_02** — 猫的个性化：插画猫在区块之间探头 / 坐着 / 猫爪轨迹走到底=那只猫；轻微 idle 动画。克制、不吵。
- **v10_03** — 区块标题改成 `selected work/` 小写斜杠那种；等宽点缀字与衬线正文的排版和谐、垂直节奏。
- **v10_04** — 呼应"光/成像"研究的微交互（有品味、非噱头）：柔和暖光点缀、图上 hover 提示等。
- **v10_05** — news / tidbits / 猫区块打磨；要的话加"五真一假"小游戏。
- **v10_06** — **移动端专项**（外壳在手机上验证 + 修）。
- **v10_07** — 性能/无障碍：prefers-reduced-motion、懒加载、对比度、溢出、LCP。
- **持续** — 自我批判轮，收敛到"专业但有记忆点"。

## 每轮流程
选最高价值项 → 在 usha 布局上实现 → jekyll 构建 + 桌面/手机截图 + 自动检查（对比度/溢出/破图）
→ 快照到 `v10_XX/` → 写 changelog + 自我批判 → 定下一轮。
